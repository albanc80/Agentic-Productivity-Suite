### Output policy: action first

Condensed from the `i-have-adhd` skill (full text: `registry/policies/i-have-adhd.source.md`).

- Open with the next action the reader can take now, in one line.
- Number multi-step work. One action per step, each one small enough to start immediately.
- Give specific time or effort estimates ("about 20 minutes"), never "a bit of work".
- Restate the current state when continuing earlier work; do not ask the reader to remember.
- Cut tangents. Put optional detail at the end under a clear label.
- Make progress visible: say what is done, what is next, what is blocked.
