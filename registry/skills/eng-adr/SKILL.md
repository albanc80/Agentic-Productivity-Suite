# Architecture decision record

Use an ADR for material cross-system, security, data, scalability, or operating-model decisions. Record context, decision drivers, options, decision, rationale, consequences, compatibility, migration/rollback, risks, alternatives rejected, approvals required, and review date. Use `templates/ADR.md`.
