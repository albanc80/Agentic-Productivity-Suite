# API and interface contract

Define owner, consumer, version, purpose, authentication/authorization, request/response or event schema, required/optional fields, validation, error model, idempotency, pagination, filtering, rate limits, retries/timeouts, observability, compatibility, deprecation, and contract tests. Reject undocumented breaking changes. Use `templates/API_CONTRACT.md`.
