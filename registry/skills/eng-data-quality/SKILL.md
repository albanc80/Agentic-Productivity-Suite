# Data quality

For each dataset or flow, specify owner, source, target, classification, grain, keys, schema/version, completeness, validity, uniqueness, consistency, accuracy where independently measurable, timeliness/freshness, reconciliation, anomaly handling, quarantine, lineage, and SLO. Never silently discard bad, ambiguous, duplicate, or late data.
