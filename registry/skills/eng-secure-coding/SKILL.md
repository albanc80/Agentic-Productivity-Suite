# Secure coding

Validate untrusted input; enforce authorization server-side; use safe parameterized data access; protect secrets; apply output encoding; prevent injection, XSS, CSRF as relevant, SSRF, insecure file handling, unsafe deserialization, sensitive-data leakage, and dependency risk. Do not weaken a control to unblock a task. Escalate material security changes for independent review.
