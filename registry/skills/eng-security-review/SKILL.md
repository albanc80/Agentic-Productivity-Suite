# Security review

Identify assets, actors, trust boundaries, attack paths, data classification, authN/authZ, dependency/supply-chain exposure, secrets, logging, and abuse scenarios. Rate findings, recommend remediation and compensating controls, and name the human authority needed for any exception. Never accept risk on behalf of the organization.
