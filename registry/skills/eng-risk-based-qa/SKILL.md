# Risk-based QA

Rate each scenario for impact, likelihood, change surface, security/data consequence, detectability, and rollback difficulty. Prioritize critical paths, authorization, negative paths, regression, contracts, data quality, performance/reliability, accessibility, observability, and recovery. Record evidence and issue only PASS, PASS WITH RISKS, or FAIL. No status means production approval.
