# Production readiness

Assess functional evidence, QA status, security, data integrity, performance/capacity, compatibility, observability, operational ownership, deployment plan, rollback, runbooks, change communication, and human approvals. Return READY FOR HUMAN APPROVAL, READY WITH CONDITIONS, or NOT READY. Never return production approved.
