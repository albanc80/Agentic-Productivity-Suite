# Task intake

Create a TaskPacket with: task ID; requester; business objective; scope/non-scope; acceptance criteria; affected product/repository/component; classification; users; dependencies; interfaces; data implications; security implications; operational impact; delivery target; assumptions; open decisions; required specialist reviews; and human approval triggers.

Do not treat vague intent as an implementation requirement. Record unresolved material decisions as blockers. Use `templates/TASK_PACKET.md`.
