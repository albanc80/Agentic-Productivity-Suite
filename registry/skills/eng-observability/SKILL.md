# Observability

Specify SLIs/SLOs, critical user journeys, structured logs with correlation IDs, redaction rules, metrics, distributed trace boundaries, health/readiness checks, dashboards, alert thresholds, ownership, runbooks, and testable failure signals. Telemetry must not expose secrets or protected information.
